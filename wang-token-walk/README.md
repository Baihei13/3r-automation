# Wang Token Walk 1.5.2 — 角色与动作帧动画

## FVTT安装

在Foundry设置页打开“附加模块 → 安装模块”，把下面地址填入“清单URL”：

https://github.com/Baihei13/3r-automation/releases/download/walk-v1.5.2/wang-token-walk.module.json

后续更新清单：https://raw.githubusercontent.com/Baihei13/3r-automation/main/wang-token-walk/module.json

安装后在世界启用本模块，GM和玩家刷新客户端。角色动画素材包需要在“角色帧”窗口单独导入。

## 功能

- 移动、通用攻击、通用施法、受击、倒地分别分配动画预设，支持四方向/八方向与播放结束后的停帧。
- 动画保存到角色列表中的原角色；新拖出的指示物继承角色动画。选中旧场上单位，在角色帧窗口补存旧配置。
- 打开角色卡右上角“角色帧”，导入或编辑预设并保存。需要以后拖出的单位显示小人时，选中指示物点击“启用走路”。
- 具体物品/动作可设置专属帧与使用、施法、攻击、伤害、暴击时机，匹配的专属帧优先于通用帧。
- 预设＋素材ZIP一起导出，中文文件名；可以导入另一服务器，或上传COS/CDN后改写图片目录。
- 内置猫耳少女与游荡者通用演示帧。没有个人角色卡、角色原图、人物预设、世界数据库或规则书。

## 1.5.2通用施法

新增独立cast分配和onCast动作时机。D35E3.1.0接入原生ItemUse.useSpell期间产生的实际施法聊天卡；查看说明、取消施法、没有实际施法卡的失败不会播放通用施法。多目标派生卡跳过，同次施法事件防重。法术不再用通用近战攻击帧兜底。保留其他模块的原生调用链，不修改系统文件。

其他系统的自动施法尚未接入，可由宏/集成调用`game.wangTokenWalk.playCast({token, item})`。移动与一般攻击/伤害的原入口保留。朝向使用最后移动方向，不自动面向目标。

## 素材包导入

单个预设导入后需分配相应动作栏并保存。整套角色预设会替换现有动画设置，已有动画请先导出备份。只写动画配置，不重置等级、HP、资源、装备、物品数量或权限。

另一服务器：选FVTT可上传目录，模块建立独立素材文件夹、上传图片并改写预设路径。图片全部处理完成后才应用设置；上传失败保留已上传文件并提示位置。

COS/CDN：解压素材ZIP，将整个assets目录上传；导入原ZIP时选择“使用已上传的图片目录”，填assets的上级目录长期网址。图片应可公开读取，并允许FVTT网址跨域读取；HTTPS世界使用HTTPS图片，不用会过期的签名网址。模块不保存桶密钥。

素材包包含package.json、命名预设JSON、README.txt和图片，清单version2，预设version1，兼容旧素材清单。模块ZIP用于安装模块，不能作为角色素材ZIP导入。

## 倒地与兼容边界

生命降低且仍高于0时播放受击；从正数降到0或以下播放death栏并保持，恢复正数后释放画面。该视觉事件可以使用倒地动画，不表示规则上已死亡。本模块不结算伤害或判定死亡。

沿用原清单Foundry最低v13、verified v14声明；本版没有运行测试、语法检查、Foundry、浏览器或游戏验证。发布与文件核对不是运行验收。v13/v14实际加载、原角色继承、ZIP上传、COS、施法取消/次数不足、单独法术优先、多目标防重及多人播放均由使用者测试。
