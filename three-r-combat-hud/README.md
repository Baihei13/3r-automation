## 功能

- 只在选中一个有操纵权限的棋子时显示。头像、名字、生命与实际资源；防御悬停显示AC/豁免及原生加值来源，豁免可点击检定。
- 攻击、法术、能力、技能、物品、实用六个主分类；技能含原生子技能，法术保留职业/法术书和环级筛选。名称可见、收藏与条目拖排。
- 剩余动作只作提醒；点击动作在当前分类中筛选，不消耗动作。实际使用走D35E原生攻击、施法、检定及聊天卡。
- 通用动作可收藏。移动累计仅限当前场景已开始战斗的成员；自由动作五尺快步独立于普通移动，战斗外不累计。
- 右下床铺“长休”打开原生休息窗口。HUD可独立启用，只依赖D35E；3r自动化和世界时间轴为可选联动。
- 指令布局及紧凑底栏；四边四角缩放、顶栏拖动与客户端保存/还原；背景透明度可调，文字图标保持清楚。
- 八套自行编写的CSS主题：绯红舞台（P5风格）、夜城终端（2077风格）、全息玻璃、古金遗迹、王庭羊皮纸、冷钢战术、暖金冒险、自选画幕。无需外部纹理或字体；自选画幕填写自己的图片路径。

0.5.1重写主题样式，并统一所有指令主题的左右两列角色卡布局。装饰切角留在背景内，不变形输入框或挤压生命轨道；更新样式加载后移除本HUD旧样式链接，避免缓存规则覆盖。收藏、法术筛选、技能/物品及原生规则入口保留。

## FVTT安装

在“附加模块 → 安装模块 → 清单URL”填入：

https://github.com/Baihei13/3r-automation/releases/download/hud-v0.5.1/three-r-combat-hud.module.json

此清单下载独立HUD安装包；后续更新通过main分支的本模块清单获取。HUD发布不改变自动化/时间轴的Latest发布。

## 手动安装

将本目录完整复制至Foundry数据目录的`Data/modules/three-r-combat-hud`，进入D35E世界启用“3r战斗HUD”。也可下载hud-v0.5.1发布页的three-r-combat-hud.zip，解压到同一目录。更新后GM与玩家各自强制刷新。
