# 3r自动化：公开规则版

版本0.4.9，Foundry VTT v14 / D35E 3.1.0；时间轴0.7.2。安装步骤见仓库根README。

## 0.4.9 夹击失败原因细化（已实现未验证）

旧说明混写未持械、不能行动、无法触及。现在记录具体同伴、武器及实际距离，区分长触及目标太近、超出触及、没有可用近战武器、不能行动、目盲、缺触及和墙壁。原判定条件、资源与武器属性保留；只在新聊天记录本次实际结果，不重算历史消息、不增加面板。

鸦嘴战锤属于双手长触及近战武器，中型角色通常能威胁10尺但不能威胁相邻5尺目标。依据[PF APG武器表](https://legacy.aonprd.com/advancedPlayersGuide/advancedGear.html)及[核心长触及规则](https://legacy.aonprd.com/coreRulebook/equipment.html)。用户反馈此前其他部分基本正常，具体新说明及合法站位结果仍需重载后确认。本轮只做文件与源码核对，没有测试、语法检查或游戏操作，未提交/推送。

## 0.4.8 侦测模式错误与攻击窗口简化（已实现未验证）

用户控制台确认0.4.7把v14侦测模式对象当数组调用 `.some()`，导致偷袭判定抛错。按本机TokenDocument键值结构统一读取模式，并补入普通照明的lightPerception检测。独立成立的夹击不再被后续视觉异常清掉，程序错误明确记入聊天，不冒充GM裁定。

移除新增的判定面板及下拉框，自动夹击回填原有勾选；手动指定或取消仅影响本次夹击，偷袭继续检查骰数、距离、视觉及免疫。每次掷骰重新判断，保留原生按钮及聊天快照。下面0.4.7面板方案已替代。

本地仅规则副本已保存，未提交/推送；GitHub仍0.4.6。本轮只读写文件，没有测试、语法检查、客户端重载或游戏验证。需用户重载各自客户端、关闭旧窗口后重新攻击；Monk模块的设置错误不在本次修改中。

## 0.4.7 初始化及自动夹击修复（已实现未验证）

0.4.6 实际报错：偷袭安装覆盖 v14 只读 renderTemplate，初始化中断，后续武器娴熟、攻击／偷袭伤害处理未接入。改用 renderDialog 和 renderChatMessageHTML，保留原生模板与按钮回调。每次合法夹击自动加入一次 +2 无名加值；与偷袭能力及视觉限制分别判断；装备远程武器的同伴不会被误算为近战威胁。聊天记录本次判定，重新显示时不根据当前站位改写历史结果。

仅文件和源码核对，没有测试或客户端验证。本地公开维护副本已更新，尚未提交／推送此版本；GitHub 上一版仍为0.4.6。重新加载、界面、骰子与多人／第三方入口须由用户验证。

公开版只安装规则合集，不创建角色，不附带原卡或写入原卡全文。条目描述来自独立规则正文文件，按实际来源书和类别整理。使用者自行建立角色、配置职业法术书与选择能力；未满足前提的专长允许保留，但无效。

## 本版修复

- 武器娴熟在 ItemRolls.rollAttack 的实际入口对本次数据选择敏捷攻击。适合的轻型/娴熟/天然武器且敏捷修正更高时替换力量，保留盾牌检定减值；1级伤害仍由力量计算，3级巧技伤害另行选择。
- 袖剑补 fin / dagger 标记；旧模块职业默认none/0补原生偷袭分组与 ceil(@level/2)，随后按真实等级计算。保留自定义公式、等级、资源与旧攻击ID。
- 同高方格按3R/PF对角5/10尺交替测距，避免相邻对角格被欧氏尺排除。不同高差待GM裁定。
- 夹击独立于偷袭骰数；相对边/角的同伴须能威胁目标。友善颜色不等于持械、触及或能行动。判定原因保存在本次聊天，原有攻击窗口不增加面板。
- 偷袭采用原生骰数，作为精准伤害参与本次伤害，不乘重击；天然1不加；PF与3R的隐蔽/类型限制分别处理。GM裁定不凭空赋予偷袭骰数。

规则出处：[武器娴熟](https://www.aonprd.com/FeatDisplay.aspx?ItemName=Weapon+Finesse)、[PF掉链子游荡者](https://www.aonprd.com/ClassDisplay.aspx?ItemName=Rogue+(Unchained))、[3R方格测距](https://www.d20srd.org/srd/combat/movementPositionAndDistance.htm)。

## 设置和使用边界

GM：游戏设置 → 配置设置 → 模组设置 → 3r自动化 → PF规则：已准备／已知的0环法术无限使用。团规默认关闭，PF女巫/先知职业本身的无限0环不依赖开关；超魔占用正数法术位仍消耗资源。

武器使用原生“创建攻击”流程。攻击前控制自己的Token并只指定一个目标；结果在实际掷骰时重新判断。未知要害、虚招、特殊视觉、不同高度及非常规规则须GM裁定。原生应用伤害流程保留，不自动扣目标HP。

黑曜石材料强化与临时增强加值分开；易碎天然1破损、再次天然1摧毁，修复只恢复记录的破损HP。黑曜石双手鸦嘴战锤与个人射程石拳术药水均明确是需要DM允许的例外，不能作为普通合法制作规则。
