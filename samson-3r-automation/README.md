# 3r自动化：公开规则版

版本0.4.6，Foundry VTT v14 / D35E 3.1.0；时间轴0.7.2。安装步骤见仓库根README。

公开版只安装规则合集，不创建角色，不附带原卡或写入原卡全文。条目描述来自独立规则正文文件，按实际来源书和类别整理。使用者自行建立角色、配置职业法术书与选择能力；未满足前提的专长允许保留，但无效。

## 本版修复

- 武器娴熟在 ItemRolls.rollAttack 的实际入口对本次数据选择敏捷攻击。适合的轻型/娴熟/天然武器且敏捷修正更高时替换力量，保留盾牌检定减值；1级伤害仍由力量计算，3级巧技伤害另行选择。
- 袖剑补 fin / dagger 标记；旧模块职业默认none/0补原生偷袭分组与 ceil(@level/2)，随后按真实等级计算。保留自定义公式、等级、资源与旧攻击ID。
- 同高方格按3R/PF对角5/10尺交替测距，避免相邻对角格被欧氏尺排除。不同高差待GM裁定。
- 夹击独立于偷袭骰数；相对边/角的同伴须能威胁目标。友善颜色不等于持械、触及或能行动。缺骰数、缺视野或同伴不满足条件时，攻击窗口和聊天显示原因。
- 偷袭采用原生骰数，作为精准伤害参与本次伤害，不乘重击；天然1不加；PF与3R的隐蔽/类型限制分别处理。GM裁定不凭空赋予偷袭骰数。

规则出处：[武器娴熟](https://www.aonprd.com/FeatDisplay.aspx?ItemName=Weapon+Finesse)、[PF掉链子游荡者](https://www.aonprd.com/ClassDisplay.aspx?ItemName=Rogue+(Unchained))、[3R方格测距](https://www.d20srd.org/srd/combat/movementPositionAndDistance.htm)。

## 设置和使用边界

GM：游戏设置 → 配置设置 → 模组设置 → 3r自动化 → PF规则：已准备／已知的0环法术无限使用。团规默认关闭，PF女巫/先知职业本身的无限0环不依赖开关；超魔占用正数法术位仍消耗资源。

武器使用原生“创建攻击”流程。攻击前控制自己的Token并只指定一个目标；结果在实际掷骰时重新判断。未知要害、虚招、特殊视觉、不同高度及非常规规则须GM裁定。原生应用伤害流程保留，不自动扣目标HP。

黑曜石材料强化与临时增强加值分开；易碎天然1破损、再次天然1摧毁，修复只恢复记录的破损HP。黑曜石双手鸦嘴战锤与个人射程石拳术药水均明确是需要DM允许的例外，不能作为普通合法制作规则。
