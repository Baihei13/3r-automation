实际入口：角色状态页/模块设置的“状态与来源”、时间轴状态详情；状态下的能力使用方式由条目详情配置。恐惧/擒抱优先法术施法者，其次唯一当前目标；变形必须指定原生形态条目。核心调用仍为原生Actor/Item、豁免、技能、攻击与伤害数据。

濒死/稳定按世界时间结算10%检定和生命流失；非致命伤害按每小时HD恢复。开世界只建立缺失计时起点，不凭空追扣历史生命。失能、恍惚、反胃的动作/移动限制及失能力竭消耗已接入。长休恢复疲乏；一小时完全休息使力竭变疲乏。不会在加载时重置玩家HP、等级、资源、数量、权限或待选项。

## 0.4.13 通用规则与原生状态（已实现未验证）

- 神导术、生命之缚等条件收益在检定前确认，取消不消耗；攻击与检定沿用原生聊天、法术位和资源入口。
- 补充有来源的法术、装备与魔宠规则条目，建立在来源书合集里，不预填角色属性、生命、装备、技能、法术准备或个人选择。前世秘术和庇护主主旨由使用者在条目操作中选择；公开版没有自动建立玩家角色的入口。
- 喙嘴翼龙魔宠通过明确使用相关能力，由主GM确认建立，关联原生Familiar职业；不在进入世界时自动创建，也不替换已有魔宠。距离先攻收益、升级及多人操作尚未验证。
- 模块效果同步到原生状态勾选，记录原有状态；停用、删除和到期恢复原有值。不能行动、反胃和整轮行动限制接入使用入口；其他状态仍沿用原生数值，不宣称全部视野、隐蔽或对抗已自动处理。
- 命令术保留法术参数、准备、施法和聊天；移动、丢弃、俯卧及行动选择由玩家和DM手动处理，没有命令专属行动锁。
- 临时增益记录施法时CL及原生持续时间，尊重已有自定义计时；模块生成的临时增益默认到期删除。攻击附注只显示实际加入的夹击或偷袭，未触发不写失败段。
- 移动借机提醒只针对已开始战斗的移动，由主GM收到提醒，确认后再攻击；仅明确进入快步模式才豁免提醒，移动距离短本身不会豁免。

用户追加FVTT安装地址要求，已补齐对应版本的安装清单；ZIP从公开Git模块子树生成，附件状态见v0.4.13发布页。没有测试、语法检查或游戏运行证据；多人权限、取消、休息、原生增益、施法/豁免/状态到期需使用者验证。抄写术的直接原书页复核、后续庇护主缺失法术及旧版本未完成规则仍保留在NEXT/COVERAGE。

源码版本0.4.13，Foundry VTT v14 / D35E 3.1.0；时间轴源码0.7.5。FVTT安装交付为v0.4.13联合发布，分别安装0.4.13 / 0.7.5。安装步骤见仓库根README。

## 0.4.9 夹击失败原因细化（已实现未验证）

鸦嘴战锤属于双手长触及近战武器，中型角色通常能威胁10尺但不能威胁相邻5尺目标。依据[PF APG武器表](https://legacy.aonprd.com/advancedPlayersGuide/advancedGear.html)及[核心长触及规则](https://legacy.aonprd.com/coreRulebook/equipment.html)。用户反馈此前其他部分基本正常，具体新说明及合法站位结果仍需重载后确认。本轮只做文件与源码核对，没有测试、语法检查或游戏操作，未提交/推送。

## 本版修复

- 武器娴熟在 ItemRolls.rollAttack 的实际入口对本次数据选择敏捷攻击。适合的轻型/娴熟/天然武器且敏捷修正更高时替换力量，保留盾牌检定减值；1级伤害仍由力量计算，3级巧技伤害另行选择。
- 袖剑补 fin / dagger 标记；旧模块职业默认none/0补原生偷袭分组与 ceil(@level/2)，随后按真实等级计算。保留自定义公式、等级、资源与旧攻击ID。
- 同高方格按3R/PF对角5/10尺交替测距，避免相邻对角格被欧氏尺排除。不同高差待GM裁定。
- 夹击独立于偷袭骰数；相对边/角的同伴须能威胁目标。友善颜色不等于持械、触及或能行动。判定原因保存在本次聊天，原有攻击窗口不增加面板。
- 偷袭采用原生骰数，作为精准伤害参与本次伤害，不乘重击；天然1不加；PF与3R的隐蔽/类型限制分别处理。GM裁定不凭空赋予偷袭骰数。

## 设置和使用边界

GM：游戏设置 → 配置设置 → 模组设置 → 3r自动化 → PF规则：已准备／已知的0环法术无限使用。团规默认关闭，PF女巫/先知职业本身的无限0环不依赖开关；超魔占用正数法术位仍消耗资源。

武器使用原生“创建攻击”流程。攻击前控制自己的Token并只指定一个目标；结果在实际掷骰时重新判断。未知要害、虚招、特殊视觉、不同高度及非常规规则须GM裁定。原生应用伤害流程保留，不自动扣目标HP。

黑曜石材料强化与临时增强加值分开；易碎天然1破损、再次天然1摧毁，修复只恢复记录的破损HP。黑曜石双手鸦嘴战锤与个人射程石拳术药水均明确是需要DM允许的例外，不能作为普通合法制作规则。
