# 公开版覆盖记录

这是功能与缺口记录，不能代替逐项规则或游戏验收。所有条目均为已实现未验证或部分实现；没有测试、语法检查、Foundry或浏览器证据。

| 功能 | 实际入口与当前边界 |
| --- | --- |
| 来源书/类别合集与中文 | catalog/content/install/item-data/spell-text；45个独立规则段落，无原卡依赖，不创建角色 |
| 武器娴熟 | ItemRolls.rollAttack复制数据替换攻击属性，盾牌检定减值；1级不替换伤害 |
| 原生偷袭骰数 | item-data迁移已知职业none/0默认值，ActorUpdater随真实等级累计，不覆盖自定义公式 |
| 夹击 | 同高方格相对边/角、双方武装/触及/可行动/墙壁；对角5/10交替；+2无名加值不重复 |
| 武器偷袭 | 实际攻击/伤害、原生精准伤害UID、不乘重击；PF/3R隐蔽/类型区别；未知条件显示原因 |
| 加值叠加 | stacking临时视图；异类、同类最高、闪避/环境、同效果、减值/内在上限；任意第三方未知类型公式不覆盖 |
| 施法职业、增益与到期 | caster-setup/effect-state/rules-bridge；真实CL、原生资源、指定武器增强、到期排除 |
| 易碎/黑曜石 | fragile天然1→破损→摧毁及破损HP记录；材料强化独立；不授予修复能力、不恢复破武损伤 |
| 时间界面 | 配套时间轴/效果详情/日历/天气/导入导出/战斗界面；权限与运行效果待使用者反馈 |
| 0环无限 | 可选世界设置；PF女巫/先知自带规则独立，超魔正数法术位仍消耗 |
| 特殊能力与法术 | 已有诅咒/巫术/种族能力入口；隐居/高等级守律与部分特殊PF法术结果尚未闭合 |
| 公开边界 | 无原卡、背景、完整角色预设、图片或私有提交历史；数据拆分仅文件核对，客户端未加载验证 |

新增规则必须记录出处、前提/等级、动作/资源、目标、时长、类型、叠加和实际入口。文字、图标或计时器不能标为实际自动计算。
